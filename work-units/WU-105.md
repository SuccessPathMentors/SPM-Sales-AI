## Optimization contract
For every Golden Intent, the V1 manifest freezes:
- direct answer requirement;
- authoritative source(s);
- no-reask known fields;
- preferred next-best-action;
- smallest optional qualifier;
- stop/override conditions;
- forbidden unsupported claims/actions;
- nearest confusion-pair intents;
- WU-104 compatibility rule;
- `irreversible_action_allowed=false`.

## Response quality rules
Unless a locked safety/support rule overrides:
1. answer the current question first;
2. reuse trusted known context;
3. do not repeat/re-ask known information;
4. ask at most one smallest relevant qualifier when useful;
5. present one clear safe next step when useful;
6. never manufacture urgency, guarantees, discounts, availability, credentials, policy outcomes, or action success.

## Implementation design
WU-105 adds no second LLM or classifier. It adds exactly one deterministic Code node:

`Build WU96-Aware Sales Agent Prompt -> Apply WU105 Golden Intent Prompt Overlay -> Generate WU92 Sales Agent Response`
